# 画面設計 — 栄養バランスチェックアプリ（仮称）

本ドキュメントは、CLAUDE.md「7. 開発ロードマップ」における「1. 画面設計フェーズ」の成果物である。
MVP機能（CLAUDE.md 4-1）を画面単位に分解し、各画面の目的・要素・遷移を整理する。

---

## 1. 画面一覧

| No | 画面名 | 対応するMVP機能 | 概要 |
|---|---|---|---|
| 1 | ログイン／サインアップ画面 | 6. 認証・ユーザー管理 | Starter Kit既存実装（`app/auth/*`）を流用 |
| 2 | 基本情報登録画面 | 1. 基本情報登録 | 初回ログイン後に年齢・性別・身長・体重を入力し、栄養基準値を算出 |
| 3 | ホーム画面（今日の記録） | 2. 食事入力 の起点 | 今日の食事記録一覧＋「記録する」導線 |
| 4 | 食事入力画面 | 2. 食事入力 | 自由文章入力タブ／食品リスト選択タブの2方式 |
| 5 | 1日の結果画面 | 3. 栄養不足判定、4. 補う食品・レシピ提案 | その日の栄養過不足＋一言コメント＋具体的な提案をセット表示 |
| 6 | 履歴・グラフ画面 | 5. 記録の振り返り | 過去の記録一覧＋栄養素推移グラフ |
| 7 | 設定画面 | 1. 基本情報登録（編集） | 基本情報の変更 |

## 2. 画面遷移図

```
[ログイン／サインアップ]
        │
        ▼（初回のみ）
[基本情報登録] ──────────┐
        │                │
        ▼                │
[ホーム（今日の記録）] ◄──┘
   │      │      │      │
   ▼      ▼      ▼      ▼
[食事入力] [1日の結果] [履歴・グラフ] [設定]
   │
   └──（登録後）→ ホームへ戻る
```

- 「1日の結果」画面へは、ホーム画面から手動で遷移する（食事ごとのリアルタイム判定ではないため）
- 「設定」画面から基本情報を編集すると、栄養基準値が再計算される

## 3. 各画面の詳細

### 3-1. ログイン／サインアップ画面

- **目的**: ユーザー認証
- **表示要素**: メールアドレス／パスワード入力、ログイン・サインアップ切り替え、パスワード再設定リンク
- **備考**: Starter Kitの既存実装（`app/auth/*`）をそのまま流用。新規実装不要
- **遷移**: ログイン成功時 → 基本情報未登録なら「基本情報登録画面」、登録済みなら「ホーム画面」

### 3-2. 基本情報登録画面

- **目的**: 個人ごとの栄養基準値算出のための情報収集
- **表示要素**:
  - 年齢（入力）
  - 性別（選択）
  - 身長（入力、cm）
  - 体重（入力、kg）
  - 「登録する」ボタン
- **UI/UX方針との対応**: 専門用語を避け、入力項目は最小限の4項目のみ
- **遷移**: 登録完了 → ホーム画面

### 3-3. ホーム画面（今日の記録）

- **目的**: 今日の食事記録状況の把握と、各機能への導線
- **表示要素**:
  - 今日入力済みの食事一覧（朝食・昼食・夕食・間食など）
  - 「食事を記録する」ボタン（食事入力画面への最短導線、タップ数最小化を重視）
  - 「今日の結果を見る」ボタン
  - 履歴・グラフ、設定へのナビゲーション
- **遷移**: 食事入力／1日の結果／履歴・グラフ／設定の各画面へ

### 3-4. 食事入力画面

- **目的**: 食べたものの記録、および今日すでに記録した内容の確認・修正
- **表示要素**:
  - 今日すでに記録した内容の一覧（食事区分ごと）。各記録に「編集」「削除」操作
  - 入力方式切り替え（自由文章入力 / 食品リスト選択）
    - 自由文章入力: テキストエリア（例: 「ご飯、鮭の塩焼き、味噌汁」）
    - 食品リスト選択: 食品名での検索・選択（複数選択可）
  - 食事区分（朝食・昼食・夕食・間食）選択
  - 「保存する」ボタン（編集中は「更新する」）
- **UI/UX方針との対応**: 入力までのタップ数・画面遷移を最小限にする（ホームから1タップで到達）。間違えた・重複した記録もこの画面内で気づいてすぐ直せるようにする
- **遷移**: 保存・更新後もこの画面に留まり、一覧を更新表示する（自動ではホームに戻らない）。「ホームに戻る」ボタンでホーム画面へ

### 3-5. 1日の結果画面

- **目的**: その日の栄養過不足を分かりやすく提示し、次の行動につなげる
- **表示要素**:
  - 栄養素ごとの過不足状態（例: 「鉄分が不足しています」を一言コメントで表示。数値の羅列は避ける）
  - 不足栄養素を補う食品・レシピの提案（例: 「レバーやほうれん草がおすすめ」「ほうれん草のお浸しはいかが？」）
  - その日入力済みの食事一覧（振り返り用）
- **UI/UX方針との対応**: 「何が」「どれくらい」不足しているかを一言コメント＋具体的提案のセットで表示
- **遷移**: ホーム画面へ戻る

### 3-6. 履歴・グラフ画面

- **目的**: 過去の記録の振り返りと傾向把握
- **表示要素**:
  - 過去の食事記録一覧（日付ごと）
  - 栄養素の推移グラフ（期間選択可能）
- **遷移**: 一覧の各日付をタップ → その日の結果画面（詳細）へ

### 3-7. 設定画面

- **目的**: 基本情報の編集
- **表示要素**:
  - 年齢・性別・身長・体重の編集フォーム
  - 「更新する」ボタン
  - ログアウトボタン
- **遷移**: 更新完了 → ホーム画面（栄養基準値は再計算）
